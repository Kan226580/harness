## 数据迁移

- 问题
> 同schema下的表因为缺少schema导致无法迁移

- 解决方案
> 1. `env.py` 中 context.configure 添加 include_schemas=True
> 2. `/version` 中的迁移文件手动添加 op.execute("CREATE SCHEMA IF NOT EXISTS auth") 和 op.execute("DROP SCHEMA IF NOT EXISTS auth CASCADE")

- 问题
> `auth` 中的 settings_json 中的 server_default 设置的json格式有误

- 解决方案
> 在json的键冒号后空一格再跟值

- 修改对比
> 1. settings_json: Mapped[dict[str, Any]] = mapped_column(
        JSONB,
        nullable=False,
        server_default=text(
            """'{"run_max_calls":null,"run_max_tokens":null,"run_max_cost_cny":null}'::jsonb"""
        ),

- mypy
> 问题
> 1. mypy 从设计上不支持「装饰器套在 @property 上面」
> 2. DbSettings/RedisSettings 有必填字段，该类零参数不可调用，不能当 default_factory

> 解决方法
> 1. 在 @computed_field 那一行加 # type: ignore[prop-decorator]
> 2. 去掉默认值，声明为必填：db: DbSettings、redis: RedisSettings
